## The stack on the site

Plain HTML / CSS / JavaScript with [three.js](https://threejs.org) for the 3D bits. The interactive fluid background, cursor robot, and scroll effects are all custom — no UI library, no bundler.

| File | Does |
| --- | --- |
| `index.html` | Markup and all the sections |
| `styles.css` | Styles + design tokens |
| `script.js` | Scroll reveal, smooth scroll, the wiring |
| `fluid.js` | Interactive fluid canvas |
| `robot.js` | The cursor-following robot |
| `assets/profile.jpeg` | Hero photo |

## Run it locally

```bash
git clone https://github.com/mightbeanshuu/portfolio.git
cd portfolio
python3 -m http.server 8000
```

Then open http://localhost:8000 — or just double-click `index.html`.

## Deploy

Ships straight to **GitHub Pages**:

1. Push to `main`
2. **Settings → Pages → Deploy from a branch** → `main` / `/ (root)`
3. Live at `https://mightbeanshuu.github.io/portfolio/`
