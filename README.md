# Anshu Aman — Portfolio

Personal portfolio site. Plain HTML/CSS/JS, no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deploy

This is ready for **GitHub Pages**:

1. Push to `main`.
2. Go to **Settings → Pages**.
3. Source: **Deploy from a branch** → `main` / `/ (root)`.
4. Site goes live at `https://mightbeanshuu.github.io/portfolio/`.

## Structure

- `index.html` — markup
- `styles.css` — styles + tokens
- `script.js` — scroll reveal + smooth scroll
- `assets/profile.jpeg` — hero photo
